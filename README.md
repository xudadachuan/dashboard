# 债市看板（bond_dashboard）

本地优先的债券固收指标看板，把分散在人民银行、中国货币网、中债、东方财富等处的零散债市数据收进一个本地网页，靠定时任务自动更新，并用 AI 生成每日市场点评，帮你大致判断市场走向、省掉每天手工拼数据的功夫。这是面向业余投资爱好者的轻量级工具，不是专业机构的终端替代。

当前为服务器版本，服务端 / 多用户部署已实现；数据更新由 云端Windows 任务计划程序定时触发（但目前已停止维护），非交易日会自动静默跳过；AI 日评在调用大模型前会先做数据完整性校验，关键输入缺失时跳过生成并写兜底文案，避免凭空编造。资金利率中的 GC001 仍为占位未接入。

本看板为个人学习 / 辅助工具。所有数据、市场温度、AI 日评均为信息聚合与参考，不构成任何投资建议，据此操作风险自负。
